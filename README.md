# Shopee Cash Bill Calculator

เว็บแอพคำนวณยอดจาก Shopee เพื่อนำไปเปิด**บิลเงินสด** และ**บิลค่าใช้จ่าย** ให้ถูกต้องตามหลักสรรพากรและแนวทางของ Shopee

## วิธีใช้
1. เปิดไฟล์ `index.html` ในเบราว์เซอร์ หรือ deploy บน GitHub Pages
2. กรอกตัวเลขจากหน้า "รายรับจากคำสั่งซื้อ" ของ Shopee
3. กดคำนวณ → ได้ยอดที่ต้องใส่ในบิลเงินสด และยอดค่าธรรมเนียมสำหรับบิลค่าใช้จ่าย

## สูตรที่ใช้
- **รายได้ (บิลเงินสด)** = ราคาสินค้า − Seller Voucher + ค่าจัดส่งที่ผู้ซื้อจ่าย
- Shopee Voucher **ไม่หัก** ออกจากรายได้ (เป็นส่วนลดที่ Shopee รับภาระ)
- **ค่าใช้จ่าย** = ค่าธรรมเนียมรวมที่ Shopee หัก (ใช้ใบกำกับภาษีรายเดือนจาก My Tax Invoices)
